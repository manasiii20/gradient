# Gradient

A gradient generator: linear, radial and mesh gradients with blur, grain, motion loops,
a saved library, and PNG / MP4 export. It's a single file, `index.html`, with no build step.

- `index.html` is the tool
- `versions/v1.0.html` is the earlier v1.0 snapshot
- `saved-for-later/` is the separate "What I saved for later" dock animation

Open `index.html` in a browser, or view it on GitHub Pages.
